## 上下文

当前项目是基于 Vue 3 + TypeScript + Vite 的在线 Markdown 编辑器。首页 (`/`) 为需认证的简单文字欢迎页。本次变更将首页改造为公开的全屏照片轮播着陆页，同时将登录路由从 `/login` 迁移至 `/lcylogin`。

约束条件：
- 不引入新的 npm 依赖
- 图片为静态资源，存放于 `public/doudouimg/`（37 张 JPEG）
- 使用现有技术栈：Vue 3 Composition API + Tailwind CSS

## 目标 / 非目标

**目标：**
- 实现沉浸式全屏照片自动轮播首页
- 将登录路由从 `/login` 改为 `/lcylogin`
- 首页无需认证即可访问
- 图片懒加载优化首屏性能

**非目标：**
- 不实现图片上传/管理后台
- 不实现触摸滑动手势
- 不改造编辑器功能或其他页面

## 决策

### 1. 图片引用方式

| 方案 | 优点 | 缺点 |
|------|------|------|
| **A. 硬编码文件名数组** ✓ | 简单可靠，构建时确定 | 新增图片需手动更新数组 |
| B. `import.meta.glob` | 自动发现文件 | public/ 目录不走 Vite 模块管线，不可用 |
| C. 运行时 fetch 目录列表 | 动态 | 静态文件服务器不支持目录列表 |

**决策：方案 A** — 在组件中维护一个文件名常量数组。图片路径格式为 `/doudouimg/<filename>.jpeg`。图片数量固定且不会频繁变动，硬编码是最简单可靠的方案。

### 2. 轮播实现方式

| 方案 | 优点 | 缺点 |
|------|------|------|
| **A. CSS transform + transition 自定义组件** ✓ | 零依赖，完全可控 | 需手写动画逻辑 |
| B. 引入第三方轮播库 | 开箱即用 | 增加包体积，与"无新依赖"原则冲突 |

**决策：方案 A** — 使用 CSS `transform: translateX()` 配合 `transition` 实现滑动效果。Vue 3 的 `setInterval` 驱动自动播放，`onUnmounted` 中清理定时器。提供左右箭头按钮和底部圆点指示器，点击时切换图片并重置自动播放计时器。

滑动机制：
```
┌──────────────────────────────────────────────────┐
│  图片条 (flex row, width = N * 100vw)             │
│  ┌──────┐┌──────┐┌──────┐┌──────┐     ┌──────┐  │
│  │ img1 ││ img2 ││ img3 ││ img4 │ ... │ imgN │  │
│  └──────┘└──────┘└──────┘└──────┘     └──────┘  │
│                                                  │
│  transform: translateX(-${currentIndex * 100}vw) │
│  transition: transform 0.5s ease-in-out          │
└──────────────────────────────────────────────────┘
```

### 3. 图片加载策略

| 策略 | 说明 |
|------|------|
| 前 3 张 | `<img>` 直接渲染，浏览器自动预加载 |
| 其余图片 | 使用 `loading="lazy"` 原生懒加载 |

无需 IntersectionObserver 等复杂方案，浏览器原生 `loading="lazy"` 已足够。

### 4. 路由变更

```
变更前                          变更后
─────────────────────────────────────────────────
/login   (guest)     →    /lcylogin   (guest)
/        (auth)      →    /           (public)
```

路由守卫调整：
- `/` 移除 `requiresAuth` meta
- 登录路由 path 从 `/login` 改为 `/lcylogin`
- 路由守卫中禁止任何重定向指向登录页；未认证用户访问受保护页面时重定向到首页 (`/`)
- `App.vue` 中所有 `/login` 引用改为 `/lcylogin`

### 5. 布局策略

```
App.vue 模板逻辑：

route.path === '/' ?
  ├── 是 → 仅渲染 <router-view />（全屏沉浸式）
  └── 否 → 渲染 header + sidebar + <router-view />
```

通过 `v-if` 条件判断实现，无需额外布局组件。

## 风险 / 权衡

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 37 张图片硬编码，新增图片需改代码 | 维护成本 | 图片数量固定，当前可接受；未来可扩展为构建时自动生成列表 |
| 首屏加载 37 张图片可能较慢 | 用户体验 | 仅预加载前 3 张，其余 lazy load；图片单张约 200KB，可接受 |
| 登录路径改为 `/lcylogin` 属于隐蔽路由 | 可发现性 | 符合需求：用户手动输入 URL 访问 |
| 轮播定时器在页面切换后可能残留 | 内存泄漏 | `onUnmounted` 中清除 `setInterval` |
| `object-fit` 原比例展示可能导致留白 | 视觉效果 | 使用 `object-fit: contain` + 深色背景填充 |
