## 为什么

当前首页 (`/`) 是一个需要登录才能访问的简单欢迎文字页，缺乏视觉吸引力。将其改造为沉浸式全屏照片自动轮播页，作为网站的公开着陆页（landing page），提升视觉展示效果。用户通过手动输入 `/lcylogin` 路径进入登录流程。

## 变更内容

- **新增**：首页 (`/`) 改为全屏沉浸式照片自动轮播页，无 header、无侧边栏
- **修改**：路由守卫 — `/` 路径移除 `requiresAuth`，变为公开页面
- **修改**：`App.vue` — header 和侧边栏仅在非 `/` 页面显示
- **不变**：登录页仍位于 `/lcylogin`，注册页仍位于 `/register`，编辑器路由 `/doc/:id` 不变

### 轮播规格

| 属性 | 值 |
|------|-----|
| 图片来源 | `/public/doudouimg/` 目录下全部 37 张 JPEG 图片 |
| 自动播放间隔 | 2 秒 |
| 切换效果 | 滑动（slide） |
| 照片尺寸 | 原比例展示 |
| 手动箭头 | 有（左右箭头按钮） |
| 底部圆点指示器 | 有（显示当前图片索引，可点击跳转） |
| Header / 导航栏 | 无（沉浸式全屏） |
| 图片加载策略 | 前几张预加载，其余懒加载 |

## 功能 (Capabilities)

### 新增功能
- `home-carousel`: 首页全屏照片自动轮播展示，包含图片加载、滑动切换动画与懒加载策略

### 修改功能
- `routing`: 首页 `/` 从需认证改为公开访问；`App.vue` 中 header 与侧边栏的显示逻辑调整为仅在非首页时展示

## 影响

| 受影响范围 | 说明 |
|-----------|------|
| `src/views/Home.vue` | 完全重写：从文字欢迎页改为轮播组件 |
| `src/router/index.ts` | 移除 `/` 路由的 `requiresAuth` meta；调整 guest 守卫逻辑 |
| `src/App.vue` | `showSidebar` 与 header 显示条件增加对 `/` 路径的判断 |
| `public/doudouimg/` | 已有 37 张 JPEG 图片，无需额外处理 |
| 无新增依赖 | 轮播功能用 Vue 3 + Tailwind CSS 原生实现 |
