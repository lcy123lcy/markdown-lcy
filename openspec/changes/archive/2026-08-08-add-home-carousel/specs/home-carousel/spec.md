## ADDED Requirements

### 需求:首页全屏照片轮播展示
首页 (`/`) 必须以沉浸式全屏方式自动轮播展示 `/public/doudouimg/` 目录下的全部 37 张 JPEG 图片。页面禁止显示 header、导航栏、侧边栏，但必须提供轮播交互控件（左右箭头和底部圆点指示器）。

#### 场景: 访问首页显示轮播
- **当** 用户访问 `/` 路径
- **那么** 系统展示全屏照片轮播页面，无 header、无侧边栏，但必须显示左右箭头按钮和底部圆点指示器

#### 场景: 轮播自动播放
- **当** 轮播页面处于展示状态
- **那么** 系统必须每 2 秒自动切换到下一张图片

#### 场景: 滑动切换效果
- **当** 图片发生切换时
- **那么** 系统必须以水平滑动（slide）动画过渡，禁止使用淡入淡出效果

#### 场景: 图片原比例展示
- **当** 图片在轮播中展示时
- **那么** 图片必须保持原始宽高比，禁止裁切或拉伸；留白区域以深色背景填充

### 需求:图片来源与加载
轮播图片必须从 `/public/doudouimg/` 目录加载全部 37 张 JPEG 文件。系统必须采用懒加载策略优化首屏性能。

#### 场景: 加载全部图片
- **当** 轮播组件初始化时
- **那么** 系统必须将 `/public/doudouimg/` 下全部 37 张 JPEG 图片纳入轮播列表

#### 场景: 预加载前几张图片
- **当** 轮播页面首次渲染时
- **那么** 系统必须立即加载前 3 张图片，确保首屏可快速展示

#### 场景: 懒加载后续图片
- **当** 轮播列表中第 4 张及之后的图片尚未进入可视区域
- **那么** 系统必须使用浏览器原生懒加载（`loading="lazy"`），禁止提前加载

## 需求:轮播交互控件
首页轮播必须提供左右箭头按钮和底部圆点指示器，允许用户手动切换图片。

#### 场景: 左右箭头按钮切换
- **当** 用户点击左侧或右侧箭头按钮
- **那么** 系统必须切换到上一张或下一张图片，并重置自动播放计时器

#### 场景: 底部圆点指示器
- **当** 首页轮播页面渲染完成
- **那么** 页面底部必须显示圆点指示器，当前图片对应的圆点必须高亮

#### 场景: 点击圆点切换图片
- **当** 用户点击底部某个圆点指示器
- **那么** 系统必须跳转到对应索引的图片，并重置自动播放计时器

#### 场景: 自动播放时圆点同步高亮
- **当** 轮播自动切换到下一张图片
- **那么** 底部圆点指示器必须同步更新高亮状态

### 需求:轮播定时器生命周期管理
轮播自动播放定时器必须在组件卸载时正确清理，禁止产生内存泄漏。

#### 场景: 组件卸载时清除定时器
- **当** 用户从首页导航到其他页面
- **那么** 系统必须清除轮播的 `setInterval` 定时器，禁止定时器继续在后台运行
