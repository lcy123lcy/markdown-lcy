## ADDED Requirements

### 需求:首页公开访问
首页 (`/`) 必须为公开页面，无需用户认证即可访问。系统禁止对 `/` 路径执行认证重定向。

#### 场景: 未登录用户访问首页
- **当** 未登录用户访问 `/` 路径
- **那么** 系统必须正常展示首页轮播内容，禁止重定向到登录页

#### 场景: 已登录用户访问首页
- **当** 已登录用户访问 `/` 路径
- **那么** 系统必须正常展示首页轮播内容

### 需求:登录路由路径变更
登录页路由路径必须从 `/login` 变更为 `/lcylogin`。系统中所有对登录页的引用必须同步更新。系统禁止将任何重定向指向登录页（包括路由守卫、未认证跳转等场景）。

#### 场景: 通过新路径访问登录页
- **当** 用户访问 `/lcylogin` 路径
- **那么** 系统必须展示登录表单页面

#### 场景: 旧路径返回 404
- **当** 用户访问 `/login` 路径
- **那么** 系统必须返回常规 404 页面，禁止重定向到 `/lcylogin`（避免暴露登录页路由）；如需重定向则必须重定向到首页轮播页 (`/`)

#### 场景: 未认证用户访问受保护页面
- **当** 未登录用户访问需要认证的页面（如 `/doc/:id`）
- **那么** 系统必须重定向到首页 (`/`)，禁止重定向到登录页

### 需求:Header与侧边栏条件显示
`App.vue` 中的 header 导航栏和文档侧边栏必须仅在非首页（`/`）路径下显示。首页必须为纯沉浸式全屏展示。

#### 场景: 首页隐藏header和侧边栏
- **当** 用户处于 `/` 路径
- **那么** 系统禁止渲染 header 导航栏和文档侧边栏

#### 场景: 非首页显示header和侧边栏
- **当** 用户处于 `/lcylogin`、`/register`、`/doc/:id` 等非 `/` 路径
- **那么** 系统必须正常渲染 header 导航栏；已登录用户在 `/doc/:id` 路径下必须显示文档侧边栏

#### 场景: 侧边栏显示逻辑不变
- **当** 用户处于已登录状态且在 `/doc/:id` 路径
- **那么** 文档侧边栏的显示逻辑必须保持与变更前一致
