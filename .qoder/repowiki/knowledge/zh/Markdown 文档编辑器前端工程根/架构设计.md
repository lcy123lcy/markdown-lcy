根目录作为单一 npm 工程入口，将前端应用（frontend_app）与规范驱动开发流程（openspec）统一编排：package.json 同时声明 Vue/CodeMirror/Tailwind 等运行时依赖以及 concurrently、@studyzy/openspec-cn 等开发工具；vite.config.ts 在开发服务器中把 /api 请求反向代理到 http://127.0.0.1:3001 的后端服务，使前端独立启动时仍能调用后端；scripts.dev 通过 concurrently 并行启动前端 dev server 与后端 pnpm dev，实现一键全栈联调；scripts.openspec* 暴露 openspec-cn CLI，配合 openspec 子模块中的 proposal/design/tasks.md 形成“提案→任务→归档”的迭代闭环。
