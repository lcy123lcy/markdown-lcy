- Pinia store 统一使用 Composition API 风格的 `defineStore('name', () => {...})` 定义，并通过 `ref`/`computed`/`watch` 管理状态与副作用。
- 所有 HTTP 请求统一通过 `api/client.ts` 的 `apiFetch` 发起，自动注入 `Authorization: Bearer <token>` 并在 401 时尝试刷新令牌后重试。
- 路由权限控制通过 `meta.requiresAuth` / `meta.guest` 声明式标注，由 `router.beforeEach` 集中处理跳转拦截。
- 认证状态在 `auth.ts` 中通过 `watch` 将 `accessToken`、`refreshTokenValue`、`user` 同步持久化到 `localStorage` 的 `auth` 键。
- WYSIWYG 编辑器的内容变更经 Turndown 转换为 Markdown 后写入 `editorStore.markdownContent`，再通过 `watch` 反向渲染 HTML 保持双向同步。
- 组件内异步错误统一通过 `ElMessage.error/warning/success` 提示用户，避免直接抛出未捕获异常。
