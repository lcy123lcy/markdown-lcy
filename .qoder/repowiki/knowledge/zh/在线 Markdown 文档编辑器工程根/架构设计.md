根目录作为统一入口，将 frontend_app（Vue3 + Pinia + Element Plus 的 Markdown 编辑器）与 openspec（OPSX 提案/设计/任务清单）两个子模块在同一 package.json 下协同：vite.config.ts 将 /api 请求反向代理到 http://127.0.0.1:3001 的后端服务，使前端独立开发时仍可调用后端；scripts.dev 通过 concurrently 并行启动前端 dev server 与 ../markdown-lcy-backend 后端，scripts.openspec* 暴露 openspec-cn CLI，配合 openspec 子模块中的 proposal/design/tasks.md 形成“提案→任务→归档”的迭代闭环。tsconfig.json、postcss.config.js、tailwind.config.js 等配置同时服务于前端构建与 openspec 文档渲染，确保前后端在类型、样式与工具链上保持一致。
